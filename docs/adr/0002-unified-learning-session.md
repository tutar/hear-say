# Use one Learning Session model for the First Round and Reviews

First Round, Review, and Free Listening activities share one framework-independent Learning Session runtime while retaining distinct stage templates and completion outcomes. The First Round uses Blind Listening, Intensive Listening, Difficult Sentence Shadowing, and Retelling; each Review Occurrence freezes Blind Listening, optional Difficult Sentence Reinforcement, and Retelling when it starts. The session records visible foreground time in exactly one Training Time category and, for mixed stages, splits Listening Time from Speaking Time by audio playback state. Free Listening never advances structured progress and contributes to Intensive Listening Time. Sessions persist resumable checkpoints and permit only one active owner tab; browser adapters supply audio, visibility, timestamps, and tab lifecycle events. Versioned Review Plans create Review Schedules whose occurrences remain pinned to the originating plan so later global edits never rewrite history.
